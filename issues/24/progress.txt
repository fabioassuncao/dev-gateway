# Progress Log — Issue #24

## Codebase Patterns
- Local facts shared by panel and CLI belong in `packages/core`; durable panel decisions stay behind the panel API.
- Core lifecycle commands must retain a Bash path that does not require Node.
- Generated Traefik writes are allowlisted by filename and written atomically with mode 0600.
- The published Portta image is built from the workspace root and may host separate process commands.
